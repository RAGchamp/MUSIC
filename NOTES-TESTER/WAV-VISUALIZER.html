What does the WAV Visualizer do?

It shows the notes sounding in two WAV files of the same song, side by side: the original recording and the file the Notes Tester made from the written notes. Every note found is a small coloured box (when it starts, how long it lasts, which note it is), so you can see at a glance where the two differ. Notes found in only one file get a red outline, and you can click any box to hear that moment. The notes are estimated from the sound with plain signal processing; no AI runs in this page.

Without a song: every box found in only one file (strength 0.25 or more). Paste it into Claude Code to fix the notes.
