What does the Notes Tester do?

It checks the notes written for a song. Test notes plays a version made only from the notes (in the song list, or in a text file of note lines), never the original recording, and you can download it as a WAV file. Compare audio files then listens to the original recording at the time of every note: is the written note really the one playing there, does it start at the right moment, and are notes missing? The result goes in a text box you can copy and paste into Claude Code to fix the notes. The comparison is plain signal processing; no AI runs in this page.
