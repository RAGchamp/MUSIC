The goal

What is an AI amplifier?

An AI amplifier is a professional who can guide an organisation to make optimal use of AI. Optimal means three things at once:
🏆
High-quality outputResults that are checked, tested and trustworthy, not just "looks right".
🪶
The fewest resourcesSmall models, plain files and local tools where they are enough; big models only where they add value.
⚡
The shortest timeIdeas that once took months to assess, tested in days or a week.

You can't guide others on this from slides alone. The first step is to build small apps and experiment, and see for yourself how AI behaves on real problems. That is what each initiative below does.

August 2026 · Coding agents

COBOL → Java migration framework

Using coding agents to modernise legacy code. The result is a deterministic converter that turns GnuCOBOL batch programs into a Java Spring Boot API in three inspectable stages (data dictionary → statement tree → Java), with a rule table that stops and names the exact COBOL line it can't convert. It was proven against a real five-program credit-card statement batch job, with an audit app to compare outputs.

Amplifier lesson: use AI to build a reliable tool, not to guess a translation. Same input, same output, verified against the real thing.

September–November 2026 · Finance

Annual Report Analyzer

A local web app for in-depth analysis of the notes to the financial statements in an annual report PDF. Ask a question such as "Analyze the company's tax-related liabilities"; the app finds the right notes deterministically, extracts them with their tables, and has Claude explain the impact on each financial statement, with follow-up questions and a report for every answer. It also rebuilds every statement as a table. Backed by 510 automated tests.

Amplifier lesson: let code find the exact facts, then let AI reason over them. Precise retrieval first is what makes the analysis trustworthy.

Stock Investment Playbook

Investment playbooks per stock, built with Claude Code from 10-K and 10-Q filings and industry templates, grounded in the value-investing ideas of Graham & Dodd's Security Analysis. Playbooks roll up into P/E cheat sheets and risk/reward rankings per industry (retail, big tech, semiconductors, restaurants, India manufacturing and more), with a plan to scale it to a 669-ticker watchlist refreshed every quarter.

October 2026 · Finance

Small Business Accounting

An accounting agent for a small business (the sample is a take-out pizza shop). The owner uploads receipts, bank and card statements, handwritten cash sheets and delivery-app reports; Claude reads each one and proposes journal entries; the owner accepts, edits or rejects them; accepted entries go into a strict double-entry ledger, from which code, never the AI, produces the financial statements and draft tax worksheets. It reuses the Annual Report Analyzer's engine.

Amplifier lesson: AI proposes, a human approves, code computes. Keep the numbers that matter out of the AI's hands.

Flow Chart App and FlowTrace AI

A browser app for complex flow charts that PowerPoint can't make: curved ribbons, knots, rings and serpentines. Its FlowTrace feature reads a picture of a flow chart and rebuilds it as editable shapes, using its own small model (a 0.25 M-parameter network that runs on a laptop), trained on synthetic diagrams the app generates itself.

Amplifier lesson: not every problem needs a giant model. A tiny, purpose-built model trained on data you generate can do the job locally, for free.

What runs through all of them

Six principles for using AI well

1
Humans leadA person sets the goal, judges the result and decides when it is good enough. AI assists.
2
Measure before you trustEvals, tests and comparisons against the real thing turn "looks right" into "is right".
3
Code for facts, AI for judgementDeterministic code finds and computes; AI reads, explains and proposes.
4
Right-size the modelUse a small local model when it is enough, and save the big ones for where they add value.
5
Prove small, then scaleMake one case work end to end, then turn it into a template or a pipeline.
6
Reuse what worksEach project borrows from the last: engines, checks and patterns compound over time.
